# yektahomes.com — целевые URL для запросов NO / DA / SV / DE

Все запросы ведут только на коммерческие страницы: главная, каталог квартир и его фильтры, разделы ЖК, услуги, ВНЖ/гражданство, иммиграция. Статьи и FAQ (`/question-answer/`) целевыми страницами не используются.

- `yektahomes_NO-DA-SV-DE_целевые_URL.xlsx` — все языки по листам, лист «Сводка»: сколько запросов ведёт на каждую страницу.
- `yektahomes_XX_целевые_URL.csv` — то же по отдельным языкам (UTF-8, разделитель `;`).
- `source/` — исходные выгрузки позиций.

Колонки: Запрос · Целевая URL · Тип страницы · Тип запроса (коммерческий / информационный) · Комментарий · позиции по датам.

«Информационный» — запрос по смыслу информационный (переезд, ипотека, процедура покупки и т.п.). Для него выбрана ближайшая коммерческая страница, а в комментарии сказано, стоит ли держать его в коммерческом ядре.

Все целевые URL проверены по Ahrefs (октябрь 2026): ответ 200, без редиректа.
